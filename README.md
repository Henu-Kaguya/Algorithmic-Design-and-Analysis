# 算法设计与分析 (Algorithmic Design and Analysis)

河南大学计算机科学与技术专业课程资料 - 算法设计与分析。

## 目录结构
- slides/: 课件与课件视频图集
- labs/: 实验 (包括实验指导与源代码)
- exercises/: 习题 (包括雨课堂测试题)
- notes/: 笔记与复习资料
- exams/: 考试复习与真题
